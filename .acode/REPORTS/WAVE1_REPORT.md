## Provider system — where NVIDIA plugs in

Sourced from `.acode/REPORTS/PROVIDER_LAYOUT.md` (sanity companion).

- Providers live at `packages/opencode/src/provider/`. Each provider exports one TypeScript file with the provider `id`, display name, base URL, supported models, default sampling parameters.
- The OpenAI provider is reused for **OpenAI-compatible** chat-completions endpoints with a different base URL.
- NVIDIA NIM (`https://integrate.api.nvidia.com/v1`) is OpenAI-compatible BUT introduces one non-standard field: `reasoning_effort` on certain reasoning models (Kimi-K2-Thinking, DeepSeek-V4, Nemotron-3-X, Qwen3-Next-Thinking, etc.). This needs a request-shape adapter.
